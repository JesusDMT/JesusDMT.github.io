# AsambleaSmart

AsambleaSmart es una aplicación web para organizar y gestionar asambleas, votaciones y participantes de forma sencilla.

Para iniciar sesión, la aplicación usa Inicio de sesión con Google y solo solicita tu nombre, correo electrónico y foto de perfil.
